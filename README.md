# Volframe - sitio web

Abrir la carpeta en Visual Studio Code y ejecutar `index.html` con la extension **Live Server** (clic derecho > Open with Live Server).

Estructura:
- index.html
- css/styles.css
- js/main.js
- img/ (logo, favicon, grupo.png, trailer-poster.jpg, equipo/)
- video/ (trailer-entre-paginas.mp4, vertical 9:16, usado en el hero)

Pendiente de editar en index.html: roles de cada integrante (Rol / Cargo), titulos y contenido del portafolio, y conectar el envio real de los formularios (main.js: handleSuggestion y handleContact).
